MMOD stack 0.1.0-rc3 — Debian 13 amd64

Includes prebuilt DMR2YSF and its managed service, Waco-compatible TS2 talkgroup prefix mapping, native MQTT FCS/YSF room commands, DT1/DT2 metadata and 10-minute RF standby unlink. Adds a configuration-preserving setup helper, converter ID lookup, and writable empty YSF directory for fresh installations. Existing station INIs and MMOD dashboard payload remain unchanged on upgrade.

Prerelease: executable, mapping, preservation and packet tests are automated; live Texas Nexus audio confirmation remains pending.
